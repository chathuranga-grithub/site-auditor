Set up Site Auditor

Use the same database link and secret key as the other computers, so they share campaigns and settings. Ask whoever set up the first computer.

Starts with postgresql:// (the DATABASE_URL).
The AUTH_SECRET: logins and saved settings (like the proxy link) are locked with it.
For campaigns' Search Console and GA4 numbers (the GOOGLE_SERVICE_ACCOUNT_JSON): the whole JSON key, as is or base64.
